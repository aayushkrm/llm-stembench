# Инструкции для экспертов STEMBench (русская версия)

Версия 1.0 — для валидации STEMBench v0.1.0-candidate.
(Авторитетная версия руководства — английская `guidelines_en.md`; при расхождениях
руководствайтесь ею.)

## Задача

Для каждого назначенного задания оцените четыре аспекта **независимо и вслепую**
(не обсуждайте задания и метки с другими экспертами до завершения раунда):

1. **Корректность эталонного ответа** — действительно ли `canonical_answer` является
   верным ответом на поставленный вопрос? (valid / invalid)
2. **Однозначность** — может ли грамотный решатель обосновать другой ответ?
   (unambiguous / ambiguous / broken)
3. **Уровень сложности** — school / university / olympiad (критерии ниже).
4. **Качество языка** (для вашего языка экспертизы): естественность, грамматика,
   терминология. Для русских заданий дополнительно: совпадает ли смысл с английским
   вариантом (можно смотреть парное задание).

Калькулятором/компьютером пользоваться можно для арифметики, но задачи решайте сами —
нужна независимая экспертная оценка заданий.

## Критерии сложности

- **school**: один концепт, 1–2 стандартных шага (типичная программа 7–9 классов).
- **university**: многошаговое применение стандартных формул первого курса или
  композиция 2–3 концептов.
- **olympiad**: сочетание ≥2 концептов с неочевидным шагом, вниманием к граничным
  случаям или олимпиадной идеей.

## Коды однозначности

| Код | Значение |
|---|---|
| `unambiguous` | ровно один обоснованный ответ |
| `ambiguous` | два обоснованных прочтения с разными ответами (укажите оба) |
| `broken` | не хватает данных, противоречие, задача нерешаема как сформулирована |

## Коды языка

| Код | Значение |
|---|---|
| `ok` | естественный текст, корректная терминология |
| `minor` | шероховатая, но однозначная формулировка |
| `major` | грамматическая/терминологическая ошибка, способная сбить решателя |
| `mismatch` | (парные задания) русский и английский варианты различаются по смыслу или данным |

## Формат выхода

Одна строка на задание (JSONL или CSV — см. `annotation_format.md`):

```
item_id | rater_id | correct(valid/invalid) | unambig(unamb/ambig/broken) |
difficulty(school/university/olympiad) | language(ok/minor/major/mismatch) |
comment (свободный текст; процитируйте проблемное место)
```

Правила:
- Проходите задания по порядку; не пропускайте (ставьте `broken`, если нерешаемо).
- Комментарий обязателен при любом отклонении от эталона или флаге неоднозначности.
- Не редактируйте текст задания — только помечайте проблемы.
- Темп: ~1–2 минуты на задание; весь набор рассчитан на одну сессию 2–3 часа.

## Разрешение конфликтов (после слепого раунда)

Координатор (не эксперт) показывает аннотаторам расхождения анонимно, только по
спорным заданиям. Каждый может пересмотреть или отстоять метку. Неурегулированные
задания уходят в арбитраж: решение большинства; при равенстве задание исключается из
принятого набора с фиксацией в логе. Все исходные и пересмотренные метки сохраняются
в релизе.

## Обучение

Перед основным набором пройдите калибровочный набор из 10 заданий
(`data/annotation_calibration/`); эталонные метки — в `calibration_answers.md`.
Расхождения обсудите с координатором до начала работы.
